# 统计页面重构 - 仪表盘风格

> **Goal:** 重构 `/stats` 页面，使用仪表盘风格，提升信息密度和视觉层次

## 页面布局

```
┌─────────────────────────────────────────────────┐
│    错题总数   学科数    错题本数    平均难度     │  ← 顶部统计数字
├─────────────────────────────────────────────────┤
│       难度分布          错误类型分布             │  ← 两个半圆仪表盘
│      (半圆仪表)          (半圆仪表)              │
├─────────────────────────────────────────────────┤
│              按学科统计表格                       │  ← 底部学科详细数据
└─────────────────────────────────────────────────┘
```

## 顶部统计数字

- 4个大字统计卡片横向排列
- 数字使用大号字体(48px)、加粗、渐变色
- 底部标签使用小号灰色字体
- 卡片使用圆角+微阴影

## 半圆仪表盘

- 使用 ECharts `pie` 系列，`radius: ['50%', '70%']`，`startAngle: 180`, `endAngle: 0`
- 难度仪表盘：5个扇区，从绿(#67c23a)到红(#f56c6c)渐变
- 错误类型仪表盘：每种错误类型一个扇区，不同颜色
- 中心显示总数或百分比
- 右侧显示图例列表

## 底部学科表格

- 保持现有数据结构
- 样式与整体仪表盘风格统一

## 视觉风格

- 卡片圆角: 16px
- 头部渐变: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
- 毛玻璃/微阴影效果
- 配色现代、层次分明
