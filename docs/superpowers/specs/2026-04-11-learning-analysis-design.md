# 学习分析报告增强方案

## 一、需求概述

在学习分析中，整合所有已有数据（错题、单词、练习）并通过LLM进行深度分析，生成更完整的学习分析报告。

## 二、数据采集范围

### 2.1 错题数据
- 难度等级（1-5）
- 错误类型
- 知识点标签
- 复习次数、正确率
- 创建时间

### 2.2 单词数据
- 复习次数
- 正确率
- 记忆曲线状态（艾宾浩斯间隔）
- 待复习标记

### 2.3 练习数据
- 练习集类型（错题/单词）
- 正确率
- 完成时长
- 练习频率

### 2.4 知识点关联
- 知识点层级关系
- 知识点间关联（用于错误溯源）

## 三、分析维度

### 3.1 薄弱点诊断
- 按知识点聚类错误频率，识别TOP10高频错误
- 挖掘"高频错误组合"（知识点+错误类型）
- 基于知识图谱关联分析深层原因

### 3.2 学习趋势分析
- 学习频率热力图（按日/周）
- 正确率变化曲线
- 投入产出比（学习时长 vs 提分效果）

### 3.3 单词掌握分析
- 掌握率分布（未掌握/学习中/已牢记）
- 记忆曲线状态分析
- 低准确率单词清单

### 3.4 个性化建议
- 针对薄弱点的练习推荐
- 记忆曲线优化建议
- 优先级排序的学习计划

**LLM分析接口**: `POST /api/stats/analysis/llm`

```json

  "weak_points": [
    {"point": "一元二次方程", "reason": "基础不扎实", "suggestion": "加强基础练习"}
  ],
  "trends": {"pattern": "正确率下降", "cause": "复习间隔过长"},

  ],
  "learning_plan": {"daily": 5, "focus_areas": ["方程", "几何"]}
}
```

│  薄弱点分析 Tab                                │

├─────────────────────────────────────────────────┤

│  ├─ 学习频率热力图（日历形式）                 │

├─────────────────────────────────────────────────┤
