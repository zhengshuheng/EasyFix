# 练习集批改页面重构方案

> **状态**: 待实现
>
> **创建日期**: 2026-04-12

## 一、需求概述

对练习集的"标记已复习"功能进行重构，优化批改流程的用户体验。

## 二、需求明细

### 2.1 按钮调整
- **文案修改**："标记已复习" → "批改"
- **颜色修改**：绿色（与操作按钮区分）

### 2.2 批改页面重构
- **布局**：表格列表展示所有题目
- **列表内容**：
  - 序号
  - 题目（原题文字或图片缩略图）
  - 答案
  - 操作列：批改正确 / 批改错误 / 查看原题 / 编辑原题
- **状态效果**：
  - 已批改正确：左侧绿色渐变背景 + 绿色边框
  - 已批改错误：左侧红色渐变背景 + 红色边框
  - 待批改：灰色边框，无背景
- **进度显示**：顶部进度条 + 正确率
- **提交规则**：必须全部批改完成才可提交（可跳着批改）

### 2.3 查看原题弹层（二合一）
- **内容**：原题、答案、图片、元信息（题目ID、知识点、错误类型）
- **功能**：支持直接在弹层内编辑题目
- **交互**：点击外部或X按钮关闭

### 2.4 图片上传
- **时机**：提交批改后
- **操作**：可选上传复习完成图片
- **功能**：拖拽上传、预览、删除
- **限制**：不限制数量和大小

## 四、技术实现

### 4.1 前端组件
- **文件**：`frontend/src/views/PracticeSets.vue`
- **弹层**：复用现有批改弹层逻辑，重构模板结构
- **图片上传**：复用现有 `uploadDialogVisible` 逻辑

### 4.2 API接口
- 复用现有接口，无需新增

### 4.3 样式
- 渐变背景色：`linear-gradient(90deg, #f0f9eb 0%, white 30%)`（正确）
- 渐变背景色：`linear-gradient(90deg, #fef0f0 0%, white 30%)`（错误）
- 边框：`border-left: 4px solid #67c23a`（正确）/ `border-left: 4px solid #f56c6c`（错误）

## 五、验收标准

1. 列表页面清晰展示所有题目
2. 批改状态有明显的视觉效果区分
3. 查看原题弹层包含完整信息
4. 编辑功能可从弹层触发
5. 图片上传为可选，可预览删除
6. 必须全部批改才能提交
