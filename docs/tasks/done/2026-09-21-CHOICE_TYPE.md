# CHOICE_TYPE — 让 AI 出题的选择题真正带选项（题型纠偏 + 选项作答）

诊断结论：练习集 23 有 2 道标为 choice 的题实际是完全的填空/问答（无任何选项）——
LLM 为凑题型配额贴了错标签；且 `Question` 表没有选项字段，选项只能塞进题干，
前端也只在阅读理解题渲染独立选项，导致"选择题"只能靠输入框作答。
（旧推断正则 `[A-Da-d]\s*[.、．)）]` 过松，也容易把"点A、点B"误判成选择题。）

- [x] 1 排查根因（数据 + 代码：prompt 无 options、题表无选项列、前端只渲染阅读题选项）
- [x] 2 后端：`Question` 加 option_a~d 列 + `main.py` 轻量迁移（`_ensure_column`）
- [x] 3 后端：prompt 增加 `options` 字段要求 + 题型与内容一致性硬约束（含反例："严禁为凑配额贴 choice"）
- [x] 4 后端：`_normalize_options` / `_extract_options_from_text`（A 起连续标签序列）/ `_finalize_question`
      （choice 必须有 ≥2 选项，否则按内容重判题型）；收紧 `_infer_question_type`（≥3 连续标签或
      ≥2 且题干有"下列/正确的是"等句式）+ `allow_choice` 开关

      + 旧数据读取时兜底（题干内嵌选项切分、错标题型纠偏，不改库）+ PDF 按题渲染选项
