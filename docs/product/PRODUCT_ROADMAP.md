# EasyFix 产品化路线图（Roadmap）

> 更新：2026-09-20
> 定位基准：**「AI 私教式学习闭环」——题是现场为你家孩子出的，错题自动追着你家孩子练，数据不出家门。**
> 覆盖作业帮的搜题/批改/讲解/学情能力，但靠 AI 生成 + 本地私有实现，不靠亿级题库与网课。
> 四项卖点：**便宜**（买断激活码 vs 年费订阅）｜**好用**（小孩端/家长端/机器端三层简单）｜**有效果**（错题闭环管到掌握）｜**有特色**（AI 动态出题 + 家长掌控 + 数据私有）。
> 不做：网课/直播/搜题流量平台（与作业帮的分界线）。
>
> 每加一个功能先问：它服务「便宜 / 好用 / 有效果 / 差异化」哪一条？

> ## 八、商业模式（规划）

> 现状盘点（2026-09-20）：当前是「本地角色系统 + 手动激活码授权」最小闭环；云端只用于远程授权/订阅管理，不做多用户 SaaS。AI 调用（deepseek-flash：出题/批改/学习报告/教程生成）是**唯一持续可变成本**——估算仅 ¥1.5～4.5/孩/月，成本极低，反而是定价优势（作业帮年费 300～800 元）。

### 变现结构（混合分层，不是二选一）

| 层 | 内容 | 定价参考 |
|---|---|---|
| 免费核心 | 做题、错题闭环、单词记忆、激励系统、家长管理（这些基本不需要 AI） | 0 元——获客 + 让家长看到闭环价值 |
| AI 订阅版 | 无限/高额度 AI 出题、AI 批改、学习报告、拍照搜题；家庭版 2～3 孩共用 | **¥10～15/月 或 ¥69～99/年**（毛利 3～5 倍） |
| BYOK 高级选项 | 设置页「自定义 AI 模型」自填 key、额度不限，技术型家长自选 | 不强制，成本自负 |

> AI 成本参考：出一张 10 题卷 ~3-5k token ≈ ¥0.01-0.02；批改一份卷 ~1-2k ≈ ¥0.005-0.01；周学习报告 ~4-6k ≈ ¥0.02-0.03。孩子正常日使用（2 卷 + 批改 + 报告）≈ ¥0.05-0.15/天。
>
> 三条定价铁律：
> 1. **软件买断/免费 + AI 服务订阅**——把「本地软件价值」与「AI 持续成本」分开收费（AI 是持续成本，必须订阅/充值制，纯买断会贴钱运营）。
> 2. **BYOK 只能做高级选项，不能做默认**——绝大多数家长不知道 API key 是什么，默认 BYOK = 双重付费感知，劝退潜在用户。
> 3. 价格锚点：99/年 vs 作业帮 300+/年；话术强调「一对一 AI 出题，不是题库」。
>
> 风险对策：API 涨价/不稳定 → 模型可配置 + 可切换更便宜模型（代码已按 provider 抽象）；滥用/白嫖 → 激活码/设备绑定 + 用量限额；OCR/语音成本 → 浏览器免费 API（已实现）+ 本地 RapidOCR 内置（规划中）。
