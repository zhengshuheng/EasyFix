# 评测设计规范（ASSESSMENT_DESIGN）

> 评测（assessment）与所有学习功能（练习/错题/报告）的设计宪法。
> **改评测相关代码前先读本文件**。教育理念错了 = 误人子弟，比代码 bug 严重。

## 0. 产品宪法：评测的教育理念（2026-09-22 与用户确认固化）

**北极星：评测的目标是提高孩子的学习积极性和学习能力，不是揠苗助长。**

核心理念：**深度优先于速度**——横向拓展（学深）优于纵向超前（学快）。

七条原则（任何需求/实现冲突时以这里为准）：

1. **不揠苗助长**：能力定位用孩子的反应做仪表盘——主动好奇 = 正循环（可给更多）；
   被动抗拒（一做就烦/哭）= 过载信号（退回来）。不用"年级进度"做标尺。
2. **深度优先**：拔高卷 = 本年级深度变式（多步/逆向/开放/说理），**不是**高年级超纲题。
   学有余力 = 学深，不是学快。
3. **变式代替重复**：同一知识点换场景/问法/条件（"7+6"变停车场、分水果、逆向求加数），
   防枯燥；重复劳动谁都烦，孩子的枯燥是真实信号。
4. **基础不放松**：基础题不是少做，是**高标准做**（一次做对 + 限时 + 检查 + 卷面），
   把细心/耐心/审题习惯练成可衡量的习惯。
5. **定位在本年级**：能力等级 = 基础 / 熟练 / 灵活应用，在本年级内定位；
   **不跨年级判"该学几年级了"**（会引导超前，破坏学校节奏）。
6. **规划给依据不给答案**：输出"强项（可拓展）/ 弱项（需巩固）"作为家长决策依据，
   **不替家长决定是否超前**；超前只作为可选轻探（"玩"不是"学"，随时可停）。
7. **诚实边界**：10-20 题只能给 ±1 年级的粗略定位——报告标注"快速摸底，非专业测评"；
   不输出"你家孩子落后了"等焦虑语言。

## 1. 三档卷型定义（需求 2 实施蓝图，未开工）

前置条件：题库难度分层（现有 754 题 95% 为同一难度，必须先打难度标签）。

| 卷型 | 难度占比（基础/中等/拓展） | 定位 | 出题要点 |
|---|---|---|---|
| 标准卷 | 40% / 40% / 20% | 检验课内掌握 | 知识点均衡，同知识点 ≤2 题 |
| 拔高卷 | 20% / 50% / 30% | 跳一跳够得着 | **本年级深度变式**：多步、逆向、开放题、说理题 |
| 拓展卷 | 10% / 40% / 50% | 摸底上限 | 灵活应用为主，可少量接触高年级概念（定位"玩"） |

- 一年级拔高 ≠ 奥数：同知识点的灵活考法 + 极少量二年级入门，不是超纲难题。
- 变式题示例（当前年级深度）：逆向求加数、多步合并、开放多解、讲题/说理。

## 2. 能力定位方向（需求 3 实施蓝图，未开工）

```
测当前年级（标准卷）
   ├─ 正确率 ≥ 90% → 上探一个年级再测（定位实际水平）
   └─ 正确率 < 60% → 下探一个年级（找"能掌握的年级"做起点）
```

- 结果：给孩子"本年级掌握等级"（基础/熟练/灵活应用）+ 可选的"实际水平年级"（±1 精度）。
- 高年级题库不足（四年级 20 题、初一 12 题）→ 上探前先评估题量，不足用 AI 补或降级跳过。

## 3. 报告/规划输出规范

- 输出：强项知识点（建议拓展方向）+ 弱项知识点（建议巩固路径）+ 下一步具体学什么、练多少。
- 禁语：禁止"落后/掉队/别人家孩子"等比较与焦虑语言；禁止用评测结果吓唬家长。
- 每次都带边界声明："快速摸底，非专业测评"。

## 4. 防回归清单（改评测时自查）

- [ ] 未答（空答案）不入错题集、不判"通过"
- [ ] 评测答对才排除错题（0.5 半对仍在错题集）
- [ ] 组卷按知识点均衡，不堆单知识点
- [ ] 不引导超前：默认卷型是标准卷；拔高/拓展入口带说明文案
- [ ] 报告按"作答时年级"归类，不被当前年级切换污染
