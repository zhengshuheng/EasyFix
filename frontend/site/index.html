在线版和本地部署版有什么区别？

在线版：注册即用，浏览器访问，无需安装，适合大多数家庭——一个孩子一个独立空间，数据保存在我们的服务器并严格隔离。本地部署版：同样需要注册订阅，但下载到电脑一键运行，所有个人数据 100% 保存在你自己电脑里，只有 AI 模型调用需要经过服务；个人、家庭、机构都适用——只要你在意数据完全在自己手里，就选它。两者功能完全一致。

在线版的数据安全吗？

每个注册用户一个独立数据库，数据互不干扰；我们提供隐私政策说明数据收集与保护方式，也支持随时导出数据。对数据自主性有更高要求的用户，可选择本地部署版。

本地部署版需要什么环境？

本地版同样需要注册订阅授权，新账号与在线版一样享受免费体验期，体验期结束按 ¥50 一次性买断。一台 Windows 电脑即可：下载解压后双击「启动」脚本，浏览器自动打开使用，无需安装额外软件。内置 754+ 题库离线可用；AI 出题、AI 补题等智能能力需联网调用大模型（可自备 API Key，不配置也能正常使用基础功能），其它所有个人数据都保存在本地。

孩子可以独立使用吗？

可以。进入空间后孩子直接点击自己的卡片即可学习；家长中心可管理小孩、配置奖励、查看报告。
